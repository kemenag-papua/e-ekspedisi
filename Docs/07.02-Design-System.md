# 07.02 - Design System

> **Document ID:** DOC-EEKS-007.02  
> **Project:** e-Ekspedisi  
> **Version:** 1.0.0 (Draft)

---

# 1. Tujuan

Dokumen ini menjadi standar desain visual dan komponen UI untuk seluruh aplikasi **e-Ekspedisi**, sehingga tampilan konsisten, mudah dipelihara, dan mudah diimplementasikan pada Vue 3 + PrimeVue + Tailwind CSS.

---

# 2. Prinsip Desain

- Sederhana
- Konsisten
- Mobile First
- Aksesibel
- Cepat dipahami
- Berorientasi produktivitas

---

# 3. Color Palette

| Token | Fungsi | Contoh |
|-------|--------|--------|
| Primary | Aksi utama | Biru |
| Secondary | Aksi sekunder | Abu-abu |
| Success | Berhasil | Hijau |
| Warning | Peringatan | Oranye |
| Danger | Kesalahan | Merah |
| Info | Informasi | Biru muda |
| Surface | Latar | Putih |
| Border | Garis | Abu muda |

> Warna akhir akan disesuaikan dengan identitas instansi.

---

# 4. Typography

| Elemen | Ukuran |
|--------|-------:|
| H1 | 32 px |
| H2 | 28 px |
| H3 | 24 px |
| H4 | 20 px |
| Body | 16 px |
| Small | 14 px |
| Caption | 12 px |

---

# 5. Grid & Spacing

- Grid 12 kolom
- Spacing berbasis kelipatan **8 px**
- Radius komponen konsisten
- Maksimal lebar konten: 1440 px

---

# 6. Ikon

Gunakan satu pustaka ikon secara konsisten (misalnya PrimeIcons atau Material Symbols).

Contoh:

- Dashboard
- Surat
- QR Code
- Kamera
- Tanda Tangan
- Pengaturan
- Audit
- Laporan

---

# 7. Button

| Tipe | Penggunaan |
|------|------------|
| Primary | Simpan |
| Secondary | Batal |
| Success | Konfirmasi |
| Danger | Hapus |
| Outline | Aksi sekunder |
| Icon | Toolbar |

State:

- Default
- Hover
- Focus
- Disabled
- Loading

---

# 8. Form Components

Standar komponen:

- Text Field
- Text Area
- Date Picker
- Dropdown
- Multi Select
- Checkbox
- Radio Button
- Switch
- File Upload
- Signature Pad

Semua field wajib menampilkan:

- Label
- Placeholder
- Validasi
- Pesan kesalahan

---

# 9. Data Table

Minimal memiliki:

- Pencarian
- Filter
- Sorting
- Pagination
- Export
- Kolom aksi

---

# 10. Status Badge

| Status | Tampilan |
|---------|----------|
| Draft | Netral |
| Menunggu Pengambilan | Warning |
| Diterima | Success |
| Ditolak | Danger |

---

# 11. Modal & Dialog

Digunakan untuk:

- Konfirmasi
- Hapus data
- Preview QR
- Preview PDF
- Detail Audit

---

# 12. Toast Notification

Jenis:

- Success
- Warning
- Error
- Information

Posisi: kanan atas.

---

# 13. Loading

- Skeleton Loader
- Spinner
- Progress Bar

---

# 14. Empty State

Contoh:

- Belum ada surat.
- Tidak ada hasil pencarian.
- Belum ada aktivitas.

---

# 15. Error State

Pesan harus jelas dan memberikan tindakan berikutnya.

Contoh:

- "Koneksi gagal. Silakan coba lagi."
- "QR Code tidak ditemukan."

---

# 16. Responsive

| Device | Lebar |
|---------|-------:|
| Mobile | <768 px |
| Tablet | 768–1024 px |
| Desktop | >1024 px |

Aturan:

- Sidebar permanen di desktop.
- Sidebar dapat disembunyikan di tablet.
- Bottom navigation pada mobile.

---

# 17. Accessibility

- Kontras warna memadai.
- Navigasi keyboard.
- Fokus terlihat jelas.
- Label pada setiap field.
- Ikon memiliki tooltip bila diperlukan.
