# Pendahuluan

Dokumen ini menjadi spesifikasi implementasi setiap layar aplikasi e‑Ekspedisi. Setiap screen memetakan kebutuhan bisnis, UI, API, database, dan pengujian.

---

# SCREEN-001 - Login

## Tujuan
Mengautentikasi pengguna sebelum mengakses aplikasi.

## Route
`/login`

## Hak Akses
Semua pengguna.

## Komponen
- Username
- Password
- Tombol Masuk

## Validasi
- Username wajib.
- Password wajib.

## API
`POST /api/v1/auth/login`

## Database
`pegawai`

## Business Rules
- BR-USR-001
- BR-SEC-002

## Acceptance Criteria
- Login berhasil mengarahkan ke Dashboard.
- Login gagal menampilkan pesan kesalahan.

---

# SCREEN-002 - Dashboard

## Route
`/dashboard`

## Tujuan
Menampilkan ringkasan kondisi surat.

## Widget

- Surat terbaru
- Aktivitas

## API
- `GET /api/v1/dashboard/summary`
- `GET /api/v1/dashboard/chart`

## Empty State
"Belum ada data."
